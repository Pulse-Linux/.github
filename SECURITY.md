# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Pulse Linux security team takes vulnerabilities seriously.

If you discover a security vulnerability in Pulse Linux (including live initramfs, overlayfs orchestrators, systemd services, AppArmor profiles, or the  CLI utility):

1. **Do NOT open a public issue.**
2. Send an email to **support@pulselinux.org** or **kalidevelopers001@gmail.com** with:
   - Vulnerability description and impact assessment
   - Proof-of-concept (PoC) code or exact reproduction commands
   - Affected component and version
3. You will receive an initial response within 48 hours.
4. We will coordinate a patched release and public disclosure following responsible disclosure practices.
